The 7 steps

  1. Open Godot — New Project, or Import the camp's project.godot.
  2. Make the character — add CharacterBody2D, name it Player.
  3. Picture + bump-shape — add Sprite2D and CollisionShape2D.
  4. Teach the keys — Project ▸ Input Map ▸ move_left, move_right, jump.
  5. Give her a brain — right-click Player ▸ Attach Script ▸ paste movement code.
  6. Add the ground — a Level with a StaticBody2D floor; drag Player in.
  7. Press ▶ GO — pick Level. Arrows to walk, Space to jump. 🎉

4 words

Node = one piece · Scene = pieces joined · Inspector = the knobs · Script = the brain.

If it breaks

  • Falls through floor? Both Player & floor need a bump-shape.
  • Won't move? Check key spelling: lowercase + underscore.
  • Flies away? jump_force must be negative (e.g. −450).
  • Red text below? Read line 1 — usually a name typo.
  • Play does nothing? Set Level as the main scene.
